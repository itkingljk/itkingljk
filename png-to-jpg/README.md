# 轻转 · PNG 转 JPG

支持单张、批量、拖拽转换，单张 JPG 和 ZIP 批量下载。

网站入口为本目录的 index.html，可静态托管。所有转换均在访问者浏览器内完成，不上传图片，不需要后端、数据库或第三方依赖。历史只记录文件信息，最近 200 条保存在访问者自己的浏览器；输出图片在清空列表、刷新或关闭页面后释放。

每批最多 50 张，每张最多 20 MB、4000 万像素，单边最多 16384 像素。透明区域填充白色，保留原图尺寸。

## 使用与部署

- GitHub Pages：按照 [部署说明](DEPLOYMENT.md) 启用 main 分支根目录发布，工具在站点的 png-to-jpg/ 路径。
- Ubuntu 24.04：只需 Nginx，将 index.html、style.css、app.js 复制到网站根目录；配置模板位于 deploy/nginx.conf。
- 离线使用：下载并使用浏览器打开 offline.html。

[查看完整部署步骤](DEPLOYMENT.md)
